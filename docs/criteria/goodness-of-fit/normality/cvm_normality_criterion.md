# Cramer-von Mises test for normality

## Description

Performs the Cramer-von Mises goodness-of-fit test against a normal distribution
with the specified mean and variance. The default reference is `N(0, 1)`.

Hypothesis of Normality
The null hypothesis is `N(mean, var)`, with both parameters specified in advance.
The statistic does not estimate them from the sample. Both fixed values appear
in `hypothesis().parameters()`. For normality with unknown
mean and variance, use a family test such as Lilliefors or Shapiro-Wilk.

Test Statistic
The statistic uses squared differences between
`scipy.stats.norm.cdf(rvs, loc=mean, scale=sqrt(var))` and expected plotting positions
for the ordered observations.

## Usage

```python
from pysatl_criterion.statistics.goodness_of_fit import (
    CramerVonMiseNormalityGofStatistic,
)


test_statistic = CramerVonMiseNormalityGofStatistic()
assert test_statistic.hypothesis().parameters() == {"mean": 0, "var": 1}
statistic_result = test_statistic.execute_statistic([-1.21, -0.83, -0.52, -0.31, -0.08, 0.14, 0.29, 0.47, 0.68, 0.91, 1.16, 1.43])
print(statistic_result)
```

## Arguments

`mean` - finite reference normal mean. Default value is `0`.

`var` - positive, finite reference normal variance (not standard deviation).
Default value is `1`. Invalid mean or variance values raise `ValueError` during construction.

`rvs` - array-like sample data passed to `execute_statistic`.

## Details

The implementation evaluates the Cramer-von Mises statistic for the supplied observations. Large or small values should be interpreted according to the statistic alternative used by the class implementation.

## Examples

Test against `N(3, 4)`, whose standard deviation is `2`:

```python
from pysatl_criterion.statistics.goodness_of_fit import (
    CramerVonMiseNormalityGofStatistic,
)


test_statistic = CramerVonMiseNormalityGofStatistic(mean=3, var=4)
assert test_statistic.hypothesis().parameters() == {"mean": 3, "var": 4}
statistic_result = test_statistic.execute_statistic([5.2, 0.8, 3.4, 1.6, 6.0, 2.2, 4.1, 3.0])
print(statistic_result)
```

Stored Monte Carlo distributions and cached critical values generated by the previous
implementation for nondefault `mean` or `var` must be recomputed: that implementation
always evaluated the standard normal CDF.
