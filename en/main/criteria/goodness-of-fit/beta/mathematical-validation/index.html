    Mathematical verification of Beta statistics¶

    Audit date: 2026-10-14. Scope: all 23 concrete classes exported by continuous/beta/beta_statistics.py, including their shared EDF/frequency kernels and hypothesis_testing/beta_bootstrap.py. See the complete catalog for every class, short code and individual page.

    Conclusion and scope of the claims¶

    The implemented definitions were checked algebraically and against independent numerical references. The current catalog contains 18 generated criteria, Neyman smooth and four fitted-Beta procedures: Ebner–Liebenberg, Raschke, Riad–Abd El Mabood and Vasicek–Kullback–Leibler. References identify published functionals or Beta-specific procedures; their critical values cannot automatically be reused after fitting parameters.

    Passing formula checks does not establish exact finite-sample significance, uniform power, or numerical accuracy for every representable positive shape.

    Null hypotheses and estimation¶

    \[ f_{a,b}(x)=\frac{x^{a-1}(1-x)^{b-1}}{B(a,b)},\qquad 0<x<1,\quad a,b>0. \]
    Criteria Hypothesis Estimation
    13 EDF, 5 frequency, Neyman smooth Both shapes fixed independently of the sample None
    Ebner–Liebenberg Both shapes unknown; support fixed Beta MLE on each call
    Raschke Both shapes unknown; support fixed Beta MLE, normal quantile transform, normal location/scale MLE on each call
    Riad–Abd El Mabood; Vasicek–KL Both shapes unknown; support fixed Beta MLE; same weight/window in each bootstrap replicate

    Specified criteria use Beta.DEFAULT.parse({"a": 2, "b": 5}); fitted criteria use Beta.DEFAULT.parse({}). No default or partially fixed shapes are accepted. All critical regions are right-tailed. Samples must be finite, real and one-dimensional; masked values are rejected rather than dropped.

    Generated formula checks¶

    For sorted observations define \(u_i=F_{a,b}(X_{(i)})\), \(r_i=i-1/2\), \(D^+=\max_i(i/n-u_i)\), \(D^-=\max_i(u_i-(i-1)/n)\) and \(W^2=1/(12n)+\sum_i(u_i-r_i/n)^2\). Counts are \(O_j\) and \(E_j=np_j>0\).

    The Beta EDF regression integrates the Beta density to obtain CDF values, then checks all thirteen statistics at five shape pairs. KS additionally uses SciPy's one-sided and two-sided tests; CvM, Watson and AD use piecewise numerical EDF integrals. Zhang and Liao–Shimokawa use explicit rank formulas, independently of production kernels. The shared-kernel suite adds high-precision Zhang references and true endpoint limits. The five frequency implementations are checked against SciPy power divergences with independently constructed bins.

    With fixed shapes the continuous probability integral transform makes EDF null laws shape-free. Ties can be evaluated, but rounding or discrete observations change the continuous-null calibration. For fixed deterministic bins and positive probabilities the usual frequency limit is \(\chi^2_{J-1}\). The default EqualProbabilityBins() uses a sample-size-dependent count; a fixed-degree chi-square claim is not made for that rule. Empty observed cells give infinity for modified log-likelihood and Neyman, which is mathematically intentional. Calibration must preserve binning settings; storage keys serialize them.

    Specialized formula checks¶

    Neyman smooth¶

    For fixed positive integer \(k\) and \(u_i=F_{a,b}(X_i)\),

    \[T_k=\frac1n\sum_{j=1}^k\left(\sum_i\sqrt{2j+1}P_j(2u_i-1)\right)^2.\]

    Shifted normalized Legendre polynomials have zero means and identity covariance under a uniform null, yielding a \(\chi^2_k\) limit for fixed \(k\). The recurrence is checked against explicit polynomials of orders 1–4 and endpoint identities at higher order. The result is shape-free under a fully specified Beta null, but fixed \(k\) does not give omnibus consistency. This applies Neyman (1937) through the PIT. k != 4 is rejected by the storage-calibration guard; use matching Monte Carlo simulation. The class does not fit unknown shapes.

    Ebner–Liebenberg¶

    With both shapes estimated by MLE and \(c_j=(\hat a+\hat b)X_j-\hat a\), the statistic is \(n\int_0^1[n^{-1}\sum_j c_j1\{X_j\ge t\} -t^{\hat a}(1-t)^{\hat b}/B(\hat a,\hat b)]^2dt\). The sorted cumulative implementation matches equation (3) of the full preprint, independently checked by quadrature and a quadratic pairwise sum. Beta-function ratios preserve the cross and constant terms. Require at least two distinct observations strictly inside the support. Refitting occurs on each bootstrap replicate; no fitted state is retained. The paper's bootstrap and consistency statements have regularity conditions, not an exact finite-sample distribution-free law.

    Raschke¶

    The author manuscript's sections 4–5 prescribe Beta MLE, normal quantile transformation, normal MLE and corrected AD. The implementation uses normal variance divisor \(n\) and correction \(1+0.75/n+2.25/n^2\). A separate weighted EDF integral checks the resulting value. At least three nonconstant interior observations are required; with two, normal standardization makes the scores \((-1,1)\) and the statistic constant. Separate Beta tails avoid 1-CDF cancellation; unrepresentable normal transforms raise an error. The paper's normal critical values are approximate. The supplied Beta bootstrap repeats both fits and is a different calibration; its validity is not implied by the Ebner–Liebenberg theorem. See Raschke's page and author manuscript.

    Numerical boundaries¶

    EDF underflow is handled with the DLMF 8.17.8 identity; a failed hypergeometric evaluation raises an error. True endpoints can legitimately yield infinity. The fitted criteria require interior, nonconstant samples and propagate fitting failures. Calibration must preserve the hypothesis and any binning/order settings.

    Package layout and import compatibility¶

    Beta follows the uniform package layout: beta/beta_statistics.py contains implementations, beta/__init__.py explicitly re-exports the public classes, and beta/__init__.pyi declares their types. The former beta.py and beta.pyi are replaced by these package files. All 25 public classes (23 concrete and two abstract) retain the module path pysatl_criterion.statistics.goodness_of_fit.continuous.beta. Regression checks cover identity between the package and implementation, old pickle references, round trips and unique criterion discovery. Private catalogs live in the implementation module and are not re-exported from the package.

    Type declarations¶

    src/pysatl_criterion/statistics/goodness_of_fit/continuous/beta/__init__.pyi declares all 23 concrete criteria and both abstract bases, including generated EDF and frequency classes. Constructor options weight, window, k and binning, scalar results, NumPy array arguments and class-level numerical helpers are typed. tests/distributions/test_beta_stub.py checks exports, inheritance, method parameter names and keyword-only defaults against runtime definitions. The generated stub is maintained with python scripts/generate_beta_stub.py; python scripts/generate_beta_stub.py --check verifies that it is current without importing the package. Generation helpers are methods of BetaStubGenerator, and type annotations are preserved through formatting. A focused mypy check of the stub and usage examples passed with --follow-imports=skip to isolate unrelated package typing issues.

    Numba execution and optimization¶

    All 23 criteria execute numerical reductions through class methods decorated with @jit(nopython=True, cache=True), without fastmath. This does not mean that SciPy distribution transforms or maximum-likelihood fitting are JIT compiled.

    KL now computes window gaps, log spacings and log densities in a single loop, without materializing those arrays. The Laplace fallback computes the minimum and shifted sample once, and calls a compiled integrand through quad(args=...). Raschke standardizes in a compiled two-pass calculation using the MLE variance with denominator n. All new helpers are class methods; the EDF log-probability callback was also moved into AbstractSpecifiedBetaGofStatistic.

    Added published criteria: independent checks¶

    Riad–Abd El Mabood (2018)¶

    See the Laplace criterion for the complete formula and original DOI. The implementation uses MLE shapes in the Kummer residual with weight \(e^{-\rho t}\). Integrating each pair uses \(\int_0^\infty t^k e^{-st}dt=k!/s^{k+1}\). Tests compare the resulting sum with independent numerical integration of \(L_n,L_n',L_n''\), for multiple weights, shapes and sample sizes.

    Source discrepancy: the expanded RF expression in Section 4 of Ebner–Liebenberg (published text) prints \(\hat\alpha^2\) in the cross-term denominator. From \(A_i=x_i(x_i-1)/\hat\alpha\) and \(B_i=1-x_i/\hat\mu\), the cross term \(A_iB_j+A_jB_i\) contains one factor \(1/\hat\alpha\), not two. We implement the squared differential-equation residual, independently verified by quadrature; the printed expansion is not used verbatim. Here \(\hat\mu=\hat\alpha/(\hat\alpha+\hat\beta)\), as defined in that published comparison. It is generally different from the sample mean. The original 2018 full text was unavailable; exact replication of its tables is not claimed. Default weight 2 is documented and included in configuration.

    Alizadeh Noughabi–Arghami (2013)¶

    See the KL criterion and original DOI. The original full text was unavailable. The general Vasicek/MLE formula was verified in Section 2 of the same author's later paper. Substituting the Beta log density yields the documented statistic. This is not the previously removed difference between theoretical and sample entropy. Tests use SciPy's explicit Vasicek estimator and independent Beta log-density calculation, including boundary window indices, reflection and negative values. The library window default is explicit and is not attributed to the 2013 paper. Zero window spacings raise an error; finite negative estimates remain unchanged. Bootstrap preserves settings and refits both shapes in every draw.

    Both new criteria reject large values. Their tests cover configuration, invalid settings/samples, no input mutation, permutation invariance and reproduction of bootstrap p-values. This validates definitions and computation, not published power tables or exact finite-sample significance.

    Verification and reproducibility¶

    The audit runs all Beta suites plus the shared EDF/frequency suites: tests/distributions/test_beta*.py, tests/statistics/test_beta_dynamic.py, test_beta_mathematical_validation.py, test_beta_published.py, test_edf.py, and test_frequency.py. These cover formula references, sample constraints, hypotheses, endpoints, small and large shapes, unchanged inputs, fitting and bootstrap reproduction.

    The documentation audit compares runtime concrete classes with all 23 pages, checks scientific URLs, Python examples, overview/navigation coverage and local links, then executes every page example. MkDocs checks HTML generation and math markup; it does not prove browser-side MathJax rendering.

    Historical source access is not uniform: the Ebner–Liebenberg full preprint and Raschke author manuscript were accessible. DOI access to Zhang, Liao–Shimokawa, Cressie–Read, Lemeshko and Neyman failed through the web tool. Their links and shared definitions are documented, but this report does not claim fresh full-text verification of those articles.

    Normal package initialization currently fails on stale imports of AbstractChi2Statistic and AbstractCrammerVonMisesStatistic from edf.py in the common initializer and unrelated distribution modules. The tests and examples therefore use an isolated continuous namespace, without introducing compatibility aliases into production. This limitation applies to the public import path and is not concealed by the numerical results.
