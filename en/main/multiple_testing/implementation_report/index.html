    Multiple testing implementation report¶

    Architectural decisions¶

    The new generic contract is pysatl_criterion.multiple_testing.AbstractMultipleTesting[InputT]. It uses mathematical input objects and a common MultipleTestingResult, without optional context dictionaries or generic keyword payloads. Ten ordinary procedures share AbstractPValueAdjustment.adjust; two adaptive procedures have only an alpha-explicit test and mark their results alpha-dependent. decisions_at prevents accidental reuse at another alpha. Holland–Copenhaver optionally accepts logical true-null bounds. Simes returns a separate scalar GlobalTestResult. Resampling procedures require explicit design assumptions and expose single-step/step-down and exact/Monte Carlo settings.

    The legacy abstract class and five adapters have been removed at the user's request. Root and api.testing exports now refer to the typed classes. This intentionally breaks the classmethod/list API; see migration. The typed API uses <= alpha, requires 0 < alpha < 1, and returns named fields.

    Joint statistic and raw-p-value matrices are separate validated containers because maxT and minP need different mathematical information. Westfall–Young maxT and minP implement these contracts. Strong FWER is conditional on valid joint exchangeability and subset pivotality, declared by the caller. The implementation cannot infer these properties from numeric arrays.

    Method inventory¶

    There are twelve per-hypothesis p-value procedures in P_VALUE_PROCEDURES, one global test in GLOBAL_TESTS, and two procedures in separate typed resampling registries. The original ten procedures have independent statsmodels fixtures and live comparisons. Rom has a high-precision recurrence oracle and analytic inversion checks. Holland–Copenhaver has independent Holm–Šidák comparisons and logical-bound examples. Simes has hand-calculated scalar examples. Westfall–Young is checked against exhaustive closed testing, hand-counted matrices, and a complete sign-flip orbit under global and partial null configurations.

    All procedures have executable documentation examples and public-export checks. Tests live in test_procedures.py, test_extended.py, and test_validation.py under tests/multiple_testing. Hommel additionally uses exhaustive Simes closure; BKY uses an independent critical-value decision oracle.

    Public API¶

    import numpy as np
from pysatl_criterion.multiple_testing import Holm, PValues

result = Holm().test(PValues(np.array([0.01, 0.04, 0.03])), alpha=0.05)
np.testing.assert_allclose(result.adjusted_p_values, [0.03, 0.06, 0.06])
assert result.rejected.tolist() == [True, False, False]

    Monte Carlo observations¶

    Each cell uses 5,000 families, 20 hypotheses, seed 62173, alpha 0.05. The mixture has five false-null p-values fixed at zero. All true-null p-values are independent uniform draws. The acceptance upper bound is alpha plus six binomial standard errors (approximately 0.0685). This is a reproducible diagnostic, not a proof.

    Method Global null Mixture Quantity
    Bonferroni 0.04480 0.04340 FWER
    Holm 0.04480 0.05400 FWER
    BH 0.04640 0.03765 FDR
    BY 0.01100 0.01160 FDR
    Two-stage BKY 0.04440 0.04920 FDR

    Statistical verification and limits¶

    Formulas were checked using primary publications/manuscripts or authoritative software documentation, plus independent numerical tests. The original Holm, Šidák, BH, BY and BKY sources and publisher abstracts for Hochberg and Hommel were consulted; full publisher PDFs were not available for every method. The R documentation and independent exhaustive closure supply additional checks for Hommel. No claim is made that inaccessible full papers were read. Original scientific authors and verified historical PySATL contributors are separate fields on every method page.

    Guarantees require valid single-test p-values. Holm/Bonferroni and BY permit arbitrary dependence; Šidák methods and the BKY guarantee here assume independence. BH permits PRDS on true nulls, while Hochberg/Hommel need valid intersection Simes tests. Uncorrected two-stage BH is explicitly exploratory without nominal FDR control asserted. Only two-stage BKY is implemented; its iterated/multistage variants are deferred. Storey needs a specified and tested pi0 estimator. Westfall–Young now provides the algorithms and independent permutation checks; the experimental resampling design, calibration and subset pivotality remain the caller's responsibility. Rom's recurrence was checked against the authors' academic supplement and independently evaluated using 70-digit arithmetic; its full original publisher paper was unavailable. Inverse critical values, not alpha-specific multipliers, define its adjusted p-values.

    Final module layout and API¶

    All production code lives in src/pysatl_criterion/multiple_testing. The generic contract is in base.py, result types in result.py, p-value contracts in pvalue/base.py, and joint-resampling contracts in resampling/base.py. Each concrete procedure has its own named module in pvalue/ or resampling/. Legacy abstract_multiple_testing.py, fdr.py, fwer.py and the former directory under hypothesis_testing have been removed. Root and api.testing exports use the typed classes. The previously deleted audit page remains deleted.
